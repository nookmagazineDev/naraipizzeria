# ยอดนับสต๊อกมาจากไหน (หน้านับสต๊อกและขอเบิก · ดูยอดรวมทุกสาขา)

## เกิดอะไรขึ้น

หน้าสาขา (โปรเจกต์ Narai-branch — https://narai-branch.vercel.app/stock/list) ย้ายเมนูสต๊อก
**ทั้งฝั่งอ่านและฝั่งเขียน** ไปอยู่บน SQL Server (ฐาน `InventoryNarai`) แล้ว
สาขานับเสร็จกดบันทึก ข้อมูลลง `dbo.stock_count` / `dbo.stock_balance` / `dbo.stock_request`

ชีท 'ข้อมูลนับสตอค' ที่ Apps Script อ่านอยู่จึงไม่มียอดนับใหม่เข้าอีกเลยตั้งแต่วันนั้น
หน้าออฟฟิศที่ยังอ่านชีทเลยค้างอยู่ที่ข้อมูลเดือนสิงหา ทั้งที่สาขานับกันทุกวัน
(อาการที่เห็น: สาขา crm ขึ้นยอดนับ 20/08 ส่วนหน้าสาขาขึ้น 10/09)

## ตอนนี้อ่านจากไหน

`getStockItems` (หน้านับสต๊อก) และ `getStockTotal` (ดูยอดรวมทุกสาขา) อ่านจาก SQL เป็นค่าเริ่มต้น

    หน้าเว็บ -> /api/stock-read -> lib/sheetsSource.js -> lib/stockCountSql.mjs
                                     ├─ ต่อ SQL ตรงจาก Vercel (lib/qcrdPool.js)  ถ้าเปิดพอร์ตไว้
                                     └─ ถอยไป host API /sheets/stock-items|stock-total ผ่าน tunnel

query กับรูปแบบคำตอบพอร์ตมาจาก `office-server/stock.js` ของ Narai-branch ทุกฟิลด์
(รวมรูปแบบวันที่ `dd/MM/yyyy HH:mm`) หน้าเว็บฝั่งนี้จึงใช้ได้โดยไม่ต้องแก้โครงข้อมูล

ถ้าอ่าน SQL ไม่ได้ จะถอยไปอ่านชีทเหมือนเดิม **พร้อมขึ้นเตือนบนหน้าเว็บ** ว่าเลขที่เห็นเป็นของเก่า
(ไม่แคชคำตอบรอบนั้นด้วย รอบหน้าจะได้ลองอ่านฐานใหม่)

## ต้องทำอะไรที่เครื่องออฟฟิศ

ทางที่ใช้จริงที่ร้านคือ host API (SQL ไม่ได้เปิดพอร์ตออกเน็ต — ดู `docs/sheets-sql-migration.md`)
endpoint `/sheets/stock-items` กับ `/sheets/stock-total` เพิ่งเพิ่ม ต้องอัปเดตเครื่องออฟฟิศก่อน:

    git pull
    powershell -ExecutionPolicy Bypass -File .\host-server\start-narai.ps1 -Restart

ไม่รีสตาร์ท = host-server ตัวเก่ายังไม่รู้จัก endpoint ใหม่ หน้าเว็บจะขึ้นเตือนแล้วถอยไปอ่านชีทเก่า

## ฝั่งเขียนยังไม่ได้ย้าย

การกดบันทึกยอดนับ/ใบเบิกจากหน้านี้ถูกปิดไว้ (`/api/stock-gas` ตอบกลับพร้อมข้อความบอกให้ไปบันทึก
ที่หน้าสาขา) เพราะถ้าปล่อยให้เขียน จะเขียนลงชีทเก่าที่ไม่มีใครอ่านแล้ว = กดบันทึกขึ้นสำเร็จแต่เลขไม่ขยับ
และข้อมูลสองระบบจะแยกกันไปอีก — หน้าออฟฟิศจึงเป็น "ดูอย่างเดียว" จนกว่าจะย้ายฝั่งเขียนตาม

## สวิตช์

| env | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `STOCK_SOURCE` | `sql` | ตั้งเป็น `sheet` เพื่อกลับไปอ่านชีทผ่าน Apps Script ชั่วคราว (ยอดจะเป็นของเก่า) และปลดล็อกฝั่งเขียนกลับมา |

คำตอบของ `/api/stock-read` มี `source: 'sql' | 'sheet'` ติดมาด้วยเสมอ เอาไว้เช็กว่ารอบนั้นอ่านจากไหน
